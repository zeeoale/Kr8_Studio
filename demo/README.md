# Public Demo Assets

These four assets were supplied by the Kr8 Studio project maintainer specifically for the public demo:

- `Demo_Sample_Audio.flac`: 30-second original demo audio.
- `16_9_Demo_Cover.png`: landscape demo artwork.
- `9_16_Demo_Cover.png`: vertical demo artwork.
- `demo_lyrics.srt`: original seven-cue lyric sample.

Run `npm run demo:prepare` to create the two self-contained projects under `examples/`.

The source code license does not automatically license these media files.

or redistributing demo media outside this repository.
