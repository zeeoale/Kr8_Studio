# Privacy

Kr8 Studio is local-first.

- Project editing, waveform analysis, preview, and export run on the user's machine.
- There is no implicit telemetry.
- Media is not uploaded automatically.
- Ollama and ComfyUI default to loopback and are enabled voluntarily.
- TKMusic access is optional and reads only the configured local library.
- Publisher providers require explicit credentials, a deliberate publish action, and the provider's own API.
- Publisher credentials are stored outside `.kr8` projects.
- The optional Instagram bridge temporarily hosts only an explicitly selected MP4 and should be privately operated.

Projects can contain sensitive media and metadata. Review them before sharing. Delete local exports and credential stores according to your own retention policy.
